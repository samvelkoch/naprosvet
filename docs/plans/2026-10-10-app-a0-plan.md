# Приложение «На_просвет», этап A0: рабочий план

Спека: `docs/specs/2026-10-10-app-pwa-design.md`. Ветка работы: `feat/app` в `naprosvet-site` от `main`. Публикация в main только по «да».

Исполнители: Sonnet-агенты по брифам ниже, по одному на задачу, последовательно (все задачи пишут в один репозиторий). Приёмка: Opus по чеклисту задачи, глазами на скриншотах 390 px и в установленном приложении на телефоне пользователя.

Проверено до начала работ:
- `<head>` трёх страниц авторов генераторы берут с сайта, значит манифест и `app.js` правятся прямо в `naprosvet-site/<автор>/index.html`.
- На всех страницах есть Яндекс.Метрика 113309794, функция `ym` глобальная.
- `voices/index.html` читает `location.hash` для выбора вопроса, у неё своя липкая шапка `.bar` и своя нижняя панель с кнопкой «Крутить барабан»; рычаг `#lever`.
- На страницах авторов: `nav.tabs` с `button[data-part]`, `nav.rail` со ссылками `a[href="#id"]` и группами `.g` (на телефоне рейка скрыта), разделы `section[id]` с `.kick b` (номер) и `h2`.
- Мифы: `chekhov` и `gary` в `<script type="application/json">`, ключ `myths` (поля `id`, `q`, `v`, текст с числом); у `brodsky` считаются в инлайн-JS и рендерятся в `#myths article` (`.q`, `.verdict`, `.num`). Рекорды: ключ `records` у `brodsky` и `gary`; у Чехова раздел `#rekordy` рендерится JS.

## Задачи

### 1. Общий слой: манифест, `app.css`, `app.js`, нижняя панель
Файлы: `manifest.webmanifest`, `icons/` (192, 512, maskable, из `favicon.svg`), `app.css`, `app.js`; правка `<head>` в `index.html`, `voices/index.html`, `brodsky/index.html`, `chekhov/index.html`, `gary/index.html` (три строки: manifest, app.css, app.js с `defer`).
Делает: нижняя панель из четырёх вкладок, только при ширине до 768 px или в `display-mode: standalone`; активная вкладка по пути; отступ снизу у `body` под панель и `env(safe-area-inset-bottom)`; на `voices/` в standalone прячет `.bar` страницы и сворачивает панель вкладок при прокрутке вниз; на главной и в «Полке» кнопка «Установить» по `beforeinstallprompt`; на iPhone в Safari (не standalone) одноразовая подсказка «Поделиться → На экран „Домой“»; при первом запуске в standalone одноразовый экран-дисклеймер; `ym` параметр визита `app=1` в standalone.
Приёмка: диф трёх страниц авторов только в `<head>`; на десктопе сайт без изменений; скриншоты 390 px всех пяти страниц с панелью; Lighthouse «installable».

### 2. Оглавление и «продолжить» на страницах авторов
Файлы: `app.js`, `app.css`.
Делает: на страницах авторов пятая кнопка «Оглавление» в панели; лист снизу, построенный из `nav.rail` (группы `.g` как части, ссылки как разделы), текущий раздел подсвечен; запоминание позиции (`localStorage`, ключ `naprosvet-pos:<автор>` = id раздела) при прокрутке, восстановление при открытии с плашкой «Продолжить с III.2 Словоискатель»; цель Метрики `toc_open`.
Приёмка: лист открывается и ведёт по `#id`; после перезагрузки страница открывается на прежнем разделе; тёмная тема.

### 3. Сборка карточек дня: `today/build.py` → `today/cards.json`
Файлы: `today/build.py`, `today/cards.json`, правка `voices/build.py` (экспорт `order`: фиксированная перестановка 300 id, seed в коде).
Делает: читает `myths` и `records` из JSON страниц Чехова и Гари; мифы и рекорды Бродского снимает из отрисованной страницы через Playwright (`#myths article`, раздел `#rekordy`), потому что они считаются в JS; складывает карточки `{author, kind: myth|record, text, verdict, num, section}` с `section` = id раздела; проверяет, что каждая ссылка `section` существует в странице автора. Слово дня в A0 не делается (данные эпох у трёх авторов разной формы), остаётся на потом.
Приёмка: `python3 today/build.py` воспроизводимо даёт один и тот же `cards.json`; число карточек по авторам в выводе; все `section` существуют.

### 4. Экран «Сегодня»: `today/index.html`
Файлы: `today/index.html`, `today/today.js`, `today/today.css` (стили на токенах из `voices/index.html`).
Делает: вопрос дня по `order` и дате старта из конфига в начале `today.js`; три ответа свёрнуты до первой фразы, имя + время, без портретов; раскрытие; «Открыть в Голосах_ →» на `../voices/#<id>`; ссылка в исследование по `today/links.json` (ручная таблица тема → раздел, допускаются пропуски); мини «Чей ответ?» с отбором ответа без маркеров (список маркеров в `today.js`), счёт за неделю в `localStorage`; «Сохранить» в `localStorage` ключ `naprosvet-shelf`; карточка «На просвет сегодня» из `cards.json` с вердиктом по касанию и ссылкой в раздел; стрелка на 30 дней назад; цели Метрики `today_open`, `answer_open`, `guess_ok`, `guess_fail`, `save`.
Приёмка: эскиз кадры 1–3 (артефакт); один и тот же вопрос в один день на двух устройствах; тёмная тема; без сети после первого открытия (после задачи 6).

### 5. Экран «Полка» и «Поделиться»
Файлы: `shelf/index.html`, `shelf/shelf.js`, `shelf/shelf.css`, `today/share.js`.
Делает: календарь месяца из точек по `localStorage` ключ `naprosvet-days` (дата пишется из `app.js` при любом открытии); список сохранённых с фильтром по автору и переходом в «Голоса_»; настройки: тема, «Установить», «Очистить»; «Поделиться» на «Сегодня» и в «Голосах_»: PNG через canvas (вопрос, ответ с обрезкой, имя, подпись «на_просвет»), Web Share с файлом, иначе скачивание; кнопки «Сохранить · Поделиться» под каждым ответом в `voices/` добавляет `app.js`; цель `share`.
Приёмка: эскиз кадр 4 и 9; карточка уходит в Telegram с iPhone и Android; сохранённое переживает перезагрузку.

### 6. Офлайн: `sw.js`
Файлы: `sw.js` (корень), регистрация в `app.js`, версия кэша из даты сборки.
Делает: предкэш списка из спеки (раздел 6); HTML и `data.json`, `cards.json` — из кэша с обновлением в фоне и плашкой «Есть новая версия»; видео портретов кэшируются после первого запроса; шрифты Google по первому запросу; удаление старых кэшей при активации.
Приёмка: Chrome DevTools offline, открываются четыре вкладки и три исследования; размер предкэша не больше 15 МБ; после изменения `brodsky/index.html` и перезагрузки дважды страница новая без переустановки.

### 7. Приёмка на телефонах и публикация
Пользователь ставит приложение на свой телефон по ссылке с ветки (GitHub Pages с ветки `feat/app` через отдельный путь или временный деплой; иначе через локальный туннель). Проверка по чеклисту спеки, раздел 11. Затем «да» → слияние в main.

## Порядок и зависимости
1 → 2 → 3 → 4 → 5 → 6 → 7. Задачи 3 и 2 независимы и могут идти параллельно, если агенты не трогают одни файлы (3 пишет только в `today/` и `voices/build.py`).
